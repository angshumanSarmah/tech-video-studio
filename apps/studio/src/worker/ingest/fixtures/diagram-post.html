Why is Quillstore so quick?

Ledgerline
Feb 14, 2023

Why is Quillstore so quick? There are 3 main reasons as shown in the diagram below.

1. Quillstore keeps its index in memory. A memory read is far quicker than a seek on a spinning disk.

2. Quillstore runs one event loop and a single worker thread that takes each request in turn.

3. Quillstore relies on a handful of compact structures built for its own workload.
